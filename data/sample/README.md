# Sample data (local only)

This directory holds a **tiny synthetic dataset** for local development. It is generated by:

```bash
python scripts/create_sample_data.py
```

Do **not** download the full competition dataset here. For training and submissions, use [Kaggle Notebooks](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection) where the data is mounted at `/kaggle/input/rsna-knee-abnormality-detection`.

Generated files mirror the official layout:

- `train.csv`, `train_series.csv`
- `test.csv`, `test_series.csv`, `sample_submission.csv`
- `train_series/{StudyInstanceUID}/{SeriesInstanceUID}/*.dcm`
- `test_series/{StudyInstanceUID}/{SeriesInstanceUID}/*.dcm`
